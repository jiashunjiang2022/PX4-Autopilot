# Phase 4.2 generated uORB schemas

These JSON files were copied from
`build/px4_fmu-v6c_default/msg/topics_sources` after the Phase 4.2 firmware
build. They are the schemas expected by the authoritative evidence checker.

- `airspeed_quality_input.json`: fixed-grid signed Pitot quality input
- `airspeed_selector_quality_status.json`: original validity, trigger, fallback,
  and final-source trace
- `ekf2_airspeed_quality.json`: sample-aligned quality and exact R diagnostic

The generated maximum untokenized uORB format is 1418 bytes. The logger has
already compiled its required 150-byte expansion margin into the v6c build.
