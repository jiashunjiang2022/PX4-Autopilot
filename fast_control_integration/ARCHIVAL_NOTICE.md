# Archival FAST material

This directory and the sibling `fast_v1_*` / `fast_v2c_*` report directories
describe earlier firmware. They are not compiled and are not instructions for
the `slow-only-isolation-20260927` branch. FAST-only host tests here have been
removed. Use `slow_only_isolation_audit/SLOW_ONLY_ISOLATION_AUDIT.md` for the
current branch status. Historical build logs, patches and hashes do not identify
the current firmware.
