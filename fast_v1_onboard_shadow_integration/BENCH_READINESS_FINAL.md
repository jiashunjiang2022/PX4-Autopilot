is the next write slot, so lag N must read N+1 slots behind it. The original
implementation was recorded as failing this off-by-one audit; the corrected
implementation was rebuilt successfully. The model frame gate emits at most
one frame per 50 ms and counts skipped periods rather than fabricating frames.

The bench scope is disarmed/non-control shadow observation. No firmware flash,
commit, or push was performed.
